# supervisor-review｜熊熊會怎麼說

模擬資訊單位主管的審閱視角：在送出報告、簡報、簽案、提案、KPI 申請之前，先用主管思維檢查一輪，取得修改建議、預判質疑與自我思考問題。

> **這是 AI 模擬，不代表任何主管本人的核定意見。** 內容依特定主管的決策偏好歸納，不同組織請自行調整。

## 觸發方式
輸入下列任一關鍵字，並貼上要審閱的內容：

**熊熊會怎麼說／熊熊說／熊主管／熊求救／熊救命**

```
熊熊說：（貼上簡報大綱／提案／進度回報）
```

建議一併提供：給誰看、何時要交、你自己的初步判斷。只輸入關鍵字而沒附內容時，會先請你補充。

## 你會得到
結論 → 做得好的地方 → 主要問題與改法 → 預判質疑與擬答 → 缺漏資訊 → 留給你思考的問題 → 下一步。每個判斷標註依據層級：【主管確認】【文件記載】【AI推論】【待確認】。

## 適用情境
上呈長官簡報、跨單位分工與權責、系統／AI／預算需求、KPI 加分審查、教育訓練與人才培育、執行追蹤與進度回報、制度與流程介面設計、新案件快速診斷。

## 限制
- 資料涵蓋有限，未討論過的領域，Skill 會明說是 AI 推論。
- 數字（如正確率門檻、天數）皆為情境舉例，不是固定標準。
- 不替業務單位撰寫其 KPI、SOP 或藍圖，只提供拆題方法與檢核問題。
